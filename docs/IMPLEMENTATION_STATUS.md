# Low-Power Sound Detection System - Implementation Status

## Project Overview

This firmware modification enables the RASynBoard to:
1. Detect high-threshold sound using the NDP120's TDK microphone
2. Wake from low-power mode when sound exceeds threshold
3. Signal the RP2040 power management HAT via GPIO to boot Raspberry Pi 5
4. Record audio to a circular buffer while Pi5 boots
5. Transfer recorded audio to Pi5 via UART for analysis

## Memory Usage Estimate

**RAM Allocation:**
- Circular buffer: 256KB (50% of 512KB total)
- FreeRTOS kernel: ~50KB
- Task stacks: ~50KB
- Other buffers: ~50KB
- **Total**: ~406KB / 512KB (79% usage)

**Recommendations:**
- Monitor heap usage: `xPortGetFreeHeapSize()`
- Can reduce buffer to 128KB if RAM pressure is high
- Ensure sufficient stack for recording task (2048 bytes minimum)
